# How can I develop checkpoint.ts?

First, install a runtime. I choose [Bun](https://bun.sh).
If you ready, change the main commands in the below with your favourite runtime. Then run them in the root folder.

Install monorepo package stuffs

```sh
bun i
```

Install pre-commit hook

```sh
pip install pre-commit # or with uv
pre-commit install
```

Run the app

```sh
cargo run
```
